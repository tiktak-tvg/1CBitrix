### Работа со стилями
На предыдущих слайдах мы рассмотрели теги, которыми ты можешь пользоваться при работе с текстом. Предлагаю сейчас посмотреть основные свойства стилей.

#### Свойство ``text-align`` определяет стиль шрифта.

Значения:

``left`` - по левому краю.

``right`` - по правому краю.

``center`` - по центру.

``justify`` - по всей ширине.

Пример:
```
div {
text-align : right; 
}
```
#### Свойство ``text-decoration`` определяет оформление текста.

Значения:

``none`` - без оформления.

``underline`` - подчеркнутый текст.

``overline`` - черта сверху.

``line-through`` - перечеркивание.

``blink (устарел)`` - мигающий текст.

Пример:
```
div { 
text-decoration : underline;
}
```
