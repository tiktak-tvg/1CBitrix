### Добавляем на страницу lesson1.html примеры работы тегов <br>, <p>, <pre>
Что нужно учесть
В самом тексте «Рассмотрим работу тегов: <br>, <p></p>, <pre></pre>» теги нужно экранировать, иначе браузер попытается их выполнить, а не показать как текст. Для этого используют HTML-сущности:

Символ	|Сущность
------- | ----------
``<``	 |``&lt;``
``>``	 |``&gt;``

о есть в HTML пишем &lt;br&gt;, а на странице видим <br>.

Код для lesson1.html
```html
<!DOCTYPE html>

     <code>&lt;pre&gt;&lt;/pre&gt;</code>.
  </p>

  <!-- BR -->
  <h2>Тег &lt;br&gt; — перенос строки</h2>
  <p>Без <code>&lt;br&gt;</code> весь текст идёт в одну строку:</p>
  <p class="example">
    Первая строка Вторая строка Третья строка
  </p>

  <p class="example">

    Третья строка
  </p>

greet("Мир");</pre>
  <p><em>Вывод:</em> <code>&lt;pre&gt;</code> сохраняет отступы и переносы
     строк — удобно для кода, стихов, схем.</p>
```

Что происходит на странице
1. Заголовок и текст «Рассмотрим работу тегов:»

В HTML пишем:
```html
<p>Рассмотрим работу тегов:
   <code>&lt;br&gt;</code>,
   <code>&lt;p&gt;&lt;/p&gt;</code>,
   <code>&lt;pre&gt;&lt;/pre&gt;</code>.
</p>
```
А на странице видим:

Рассмотрим работу тегов: ``<br>, <p></p>, <pre></pre>``.

Теги показаны как текст, потому что < и > заменены на ``&lt; и &gt;``.

2. <br> — перенос строки
Без тега:
```html
<p>Первая строка Вторая строка Третья строка</p>
```
Браузер сжимает всё в одну строку: «Первая строка Вторая строка Третья строка».

С тегом:

html
<p>
  Первая строка<br>
  Вторая строка<br>
  Третья строка
</p>
Каждая часть — с новой строки, но в одном абзаце (без отступов между строками).

3. ``<p>`` — абзац
```html
<p>Первый абзац</p>
<p>Второй абзац</p>
<p>Третий абзац</p>
```
Каждый ``<p>`` — отдельный абзац. Браузер автоматически добавляет:

внешний отступ сверху и снизу ``(margin)``;

начинает новый абзац с новой строки.
<pre>
Разница с <br>: <br> просто переносит строку, а <p> создаёт смысловой абзац.
</pre>
4. ``<pre>`` — сохранение форматирования
Обычный <p>:

html
<p>
  function greet(name) {
      return "Привет, " + name + "!";
  }
</p>

На странице все отступы и переносы сожмутся в одну строку.

``<pre>``:

```html
<pre>function greet(name) {
    return "Привет, " + name + "!";
}

greet("Мир");</pre>
```
На странице сохранятся все пробелы и переносы — в точности как в исходнике. Поэтому <pre> используют для кода, стихов, схем.

Проверка

Сохраните lesson1.html.

Откройте в браузере.
<pre>
Убедитесь, что:

в начале страницы теги <br>, <p></p>, <pre></pre> показаны как текст, а не выполнены;

в разделе <br> строки идут друг под другом без отступов между ними;

в разделе <p> между абзацами есть отступы;

в разделе <pre> отступы и пустая строка перед greet("Мир") сохранились.
</pre>

Частые ошибки
Ошибка	Что будет	Как исправить
Написать <br> в тексте без экранирования	Браузер сделает перенос, а не покажет тег	Писать &lt;br&gt;
Использовать <br><br> вместо <p>	Нет смысловых абзацев, плохо для SEO и скринридеров	Абзацы — через <p>
Оборачивать код в <p> без <pre>	Пропадут отступы и переносы	Использовать <pre><code>...</code></pre>
Забыть </p>	Браузер может «починить» разметку непредсказуемо	Всегда закрывать парные теги
Мини-итог
<br> — перенос строки, не создаёт абзац.

<p> — абзац с автоматическими отступами, основной тег для текста.

<pre> — сохраняет форматирование (пробелы, переносы), для кода и схем.

Теги в тексте страницы показывают через &lt; и &gt;.
