#### Селекторы
Описание: Селектор — это часть CSS-правила, которая указывает, к каким HTML-элементам применить стили. Синтаксис:
```css
селектор {
  свойство: значение;
}
```
#### Виды селекторов начального уровня:

Селектор	|Пример	|Что выбирает
---------- | ----- | -----------
Универсальный	 |``*``	 |Все элементы
Типа (тега)	 |``p`` |Все теги ``<p>``
Класса	 |``.card``	 |Все элементы с ``class="card"``
Идентификатора	 |``#header``	 |Элемент с ``id="header"``

#### Универсальный селектор
Описание: Обозначается звёздочкой ``*.`` Выбирает все элементы на странице. Часто используется для сброса отступов и базовых настроек.

Пример:

```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
```
#### HTML:
```html
<h1>Заголовок</h1>
<p>Абзац</p>
<div>Блок</div>
```
```txt
Пояснение: правило * применится ко всем трём элементам сразу — у всех пропадут внешние и внутренние отступы. Универсальный селектор удобен для «обнуления» стилей браузера, но не стоит злоупотреблять им — он применяется к каждому элементу и может замедлять отрисовку на больших страницах.
```
#### Селекторы типа
Описание: Селектор типа (или селектор тега) выбирает все элементы с указанным именем тега. Записывается просто именем тега без точки и решётки.

Пример:
```css
h1 {
  color: #2c3e50;
}

p {
  color: #333333;
  line-height: 1.6;
}

a {
  text-decoration: none;
  color: #3498db;
}
```
#### HTML:
```html
<h1>Заголовок</h1>
<p>Первый абзац</p>
<p>Второй абзац</p>
<a href="#">Ссылка</a>
```
```
Пояснение: правило p { ... } применится к обоим абзацам, потому что селектор типа выбирает все элементы этого тега на странице. Это удобно для базовых стилей, но не даёт точечного управления — если нужно оформить только один абзац иначе, используют классы или id.
```
#### Селекторы класса
Описание: Селектор класса выбирает элементы с определённым значением атрибута ``class``. Записывается через точку: .имя-класса.

Особенности:
- один класс можно применить ко многим элементам;
- у одного элемента может быть несколько классов через пробел: ``class="card big"``;
- имена классов чувствительны к регистру;
- класс не должен начинаться с цифры.
- Селекторы класса.

Пример

#### CSS:
```css
.card {
  background: white;
  padding: 16px;
  border: 1px solid #ddd;
  border-radius: 8px;
}

.highlight {
  background: #fff8e1;
  border-color: #f0c000;
}

.big {
  font-size: 20px;
}
```
#### HTML:
```html
<div class="card">Обычная карточка</div>

<div class="card highlight">Карточка с выделением</div>

<div class="card big">Крупная карточка</div>

<div class="card highlight big">
  Карточка с двумя классами сразу
</div>
```
```
Пояснение:

первый блок получит только стили .card;

второй — .card + .highlight;

третий — .card + .big;

четвёртый — .card + .highlight + .big.

Класс — самый гибкий и часто используемый селектор. Один и тот же класс переиспользуется на разных элементах, а элемент может комбинировать несколько классов.
```
#### Селекторы класса. Задание
Задание: Создайте страницу со списком новостей. Оформите её с помощью классов:
- Каждая новость — блок ``<div class="news-item">`` с белым фоном, отступами и рамкой.
- Важная новость дополнительно имеет класс important с красной рамкой.
- Новость-анонс дополнительно имеет класс announce с жёлтым фоном.

Решение:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Новости</title>
  <style>
    .news-item {
      background: white;
      padding: 16px;
      border: 1px solid #ddd;
      border-radius: 8px;
      margin-bottom: 12px;
    }

    .important {
      border: 2px solid #e74c3c;
    }

    .announce {
      background: #fff8e1;
    }
  </style>
</head>
<body>
  <h1>Новости</h1>

  <div class="news-item">
    <h2>Обычная новость</h2>
    <p>Текст обычной новости.</p>
  </div>

  <div class="news-item important">
    <h2>Важная новость</h2>
    <p>Текст важной новости.</p>
  </div>

  <div class="news-item announce">
    <h2>Анонс</h2>
    <p>Текст анонса.</p>
  </div>
</body>
</html>
```
```txt
Пояснение: класс .news-item задаёт общий вид всем новостям, а дополнительные классы .important и .announce точечно меняют отдельные блоки. Такой подход называется «базовый класс + модификатор» — он удобен и масштабируем.
```

#### Селекторы идентификаторы
Описание: Селектор идентификатора выбирает элемент с конкретным значением атрибута id. Записывается через решётку: #имя-id.

Правила:

- id уникален на странице — не должно быть двух элементов с одинаковым id;
- у одного элемента только один id (в отличие от классов);
- id имеет более высокий приоритет, чем класс и тег;
- id часто используется для якорей ``(<a href="#contacts">)`` и для JS.

#### CSS:

```css
#header {
  background: #2c3e50;
  color: white;
  padding: 20px;
}

#main-title {
  font-size: 28px;
}

#contacts {
  margin-top: 40px;
  padding: 20px;
  background: #f4f4f4;
}
```
#### HTML:
```html
<header id="header">
  <h1 id="main-title">Мой сайт</h1>
</header>

<main>
  <p>Основной контент страницы.</p>
</main>

<footer id="contacts">
  <p>Свяжитесь с нами: test@example.com</p>
</footer>
```

<img width="1379" height="301" alt="image" src="https://github.com/user-attachments/assets/fc3cc249-b0a8-416d-a173-4f3e4673396d" />

Пояснение:

``#header`` применится только к ``<header>``;

``#main-title`` — только к конкретному ``<h1>``;

``#contacts`` — только к ``<footer>``.

Если у элемента одновременно есть ``id`` и ``class``, стили ``id`` будут иметь приоритет при конфликте.

##### Когда что использовать:

Ситуация	|Что выбрать
--------- | --------------------
Оформление повторяющихся блоков	 |класс
Уникальный блок (шапка, подвал)	 |класс или id
Якорь для ссылки	 |id
Обращение из JavaScript	 |id
Сложные составные стили	 |класс

Рекомендация: для оформления чаще используют классы, id — для уникальных элементов и якорей.

#### Итоговая шпаргалка
```txt
css
*         { }   /* все элементы */
p         { }   /* все теги <p> */
.card     { }   /* все элементы с class="card" */
#header   { }   /* элемент с id="header" */
.card.big { }   /* элементы, у которых есть оба класса */
.card p   { }   /* все <p> внутри .card */
```

#### Приоритет селекторов (от низкого к высокому):
```
Универсальный *

Тег p

Класс .card

Класс + класс .card.big

Идентификатор #header

Встроенный стиль style="..."

!important (использовать крайне редко)

Практические советы:

для оформления — классы;

для уникальных элементов и якорей — id;

не дублируйте id;

избегайте !important;

проверяйте, какой стиль победил, через DevTools (F12 → Elements → Styles).
```
