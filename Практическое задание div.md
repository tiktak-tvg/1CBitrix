### Представь, у нас есть фрагмент книги. Оформи его по своему желанию, используя теги и свойства, представленные на страницах выше. Также не забудь про контейнер, в который мы можем помещать контент. 

Давайте создадим красивый фрагмент книги, используя контейнер ``<div>`` и все теги для работы с текстом, которые мы изучили.

В качестве примера возьмем отрывок из «Алисы в Стране чудес» Льюиса Кэрролла.

Мы используем:

- ``<div>`` — как «страницу книги» (контейнер).

- Теги текста — заголовки, абзацы, курсив, выделение, цитаты, линии.

- CSS-свойства — фон, отступы, шрифты, выравнивание, тени, рамки и т.д.

Вот готовый и полностью рабочий код:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Фрагмент книги</title>
  <style>
    /* Общие стили для всей страницы (фон вокруг книги) */
    body {
      background-color: #e8dfd3; /* Цвет старой бумаги */
      font-family: 'Georgia', serif; /* Шрифт с засечками, как в книгах */
      padding: 40px 20px;
      margin: 0;
    }

    /* Стили для нашего главного контейнера div */
    .book-page {
      background-color: #fffdf8; /* Светлый фон страницы */
      max-width: 650px;          /* Ограничиваем ширину, чтобы было похоже на книгу */
      margin: 0 auto;            /* Центрируем блок по горизонтали */
      padding: 40px 50px;        /* Внутренние отступы (воздух внутри страницы) */
      border: 1px solid #d1c7b8; /* Тонкая рамка */
      border-radius: 4px;        /* Легкое скругление углов */
      box-shadow: 0 10px 25px rgba(0,0,0,0.1); /* Тень, чтобы страница выделялась */
    }

    /* Стили для заголовков */
    .book-page h2 {
      text-align: center;        /* Выравнивание по центру */
      color: #4a3b32;            /* Темно-коричневый цвет */
      text-transform: uppercase; /* Все буквы заглавные */
      letter-spacing: 3px;       /* Разрядка между буквами */
      text-shadow: 1px 1px 2px rgba(0,0,0,0.1); /* Легкая тень для текста */
      margin-bottom: 5px;
    }

    .book-page h3 {
      text-align: center;
      color: #8c7765;
      font-style: italic;
      font-weight: normal;
      margin-top: 0;
      margin-bottom: 30px;
      border-bottom: 1px dashed #d1c7b8; /* Пунктирная линия снизу */
      padding-bottom: 15px;
    }

    /* Стили для абзацев */
    .book-page p {
      color: #333;
      line-height: 1.8;          /* Межстрочный интервал для удобного чтения */
      text-align: justify;       /* Выравнивание по ширине (ровные края) */
      text-indent: 30px;         /* Красная строка (отступ первой строки) */
      margin-bottom: 15px;
    }

    /* Стили для прямой речи */
    .dialogue {
      text-align: center;
      font-style: italic;
      color: #5a5a5a;
      margin: 20px 0;
      word-spacing: 2px; /* Чуть больше расстояние между словами */
    }

    /* Буквица (первая большая буква) */
    .drop-cap {
      float: left;               /* Обтекание текстом */
      font-size: 4em;            /* Большой размер */
      line-height: 0.8;          /* Убираем лишнее пространство */
      margin-right: 10px;
      margin-top: 5px;
      color: #a0522d;            /* Цвет буквицы */
      font-weight: bold;
    }
  </style>
</head>
<body>

  <!-- Наш контейнер для страницы -->
  <div class="book-page">
    
    <h2>Алиса в Стране чудес</h2>
    <h3>Глава 1. Вниз по кроличьей норе</h3>

    <p>
      <span class="drop-cap">А</span>лисе надоело сидеть без дела рядом с сестрой на берегу и заглядывать в книжку, в которой не было ни картинок, ни разговоров.
    </p>

    <p>
      Вдруг мимо неё пробежал <strong>Белый Кролик</strong> с розовыми глазами. В руках он держал <em>карманные часы на цепочке</em> и, глядя на них, бормотал:
    </p>

    <!-- Блок с прямой речью -->
    <p class="dialogue">
      — Ах, боже мой! Ах, боже мой! Я опоздаю!
    </p>

    <p>
      Алиса вскочила на ноги: ей ещё <ins>никогда</ins> не приходилось видеть кролика с карманными часами, да ещё и говорящего по-человечески. Любопытство взяло верх, и она побежала за ним через поле.
    </p>

    <hr>

    <p style="text-align: right; text-indent: 0; font-size: 0.9em; color: #888;">
      <small>Отрывок из книги Льюиса Кэрролла</small>
    </p>

  </div>

</body>
</html>
```
