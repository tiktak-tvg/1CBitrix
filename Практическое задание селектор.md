### Задание
Мы смогли окрасить второй абзац в голубой цвет. 

Попробуй самостоятельно окрасить третий абзац в произвольный цвет.

Подсказка:

Необходимо добавить класс для третьего абзаца. 

Проверить подключение файла со стилями (вдруг, отвалились). 

В стилях прописать новое правило для нового класса.

### Решение
Предположим, у нас есть такой HTML-код с тремя абзацами (второй уже покрашен в голубой цвет):

#### Шаг 1. Добавляем класс третьему абзацу (HTML)
Откройте ваш файл index.html и найдите третий тег <p>. Добавьте ему атрибут class с любым названием. Назовем его, например, third-paragraph или custom-color.
```html
<body>
  <p>Это первый абзац.</p>
  
  <!-- Второй абзац уже имеет класс для голубого цвета -->
  <p class="blue-text">Это второй (голубой) абзац.</p>
  
  <!-- Добавляем класс третьему абзацу -->
  <p class="custom-color">А это третий абзац, который мы сейчас покрасим!</p>
</body>
```
#### Шаг 2. Проверяем подключение стилей (HTML)
Убедитесь, что в самом верху, внутри тега <head>, у вас есть строка подключения вашего файла CSS. Если она «отвалилась», стили не сработают.
```html
<head>
  <meta charset="UTF-8">
  <title>Моя страница</title>
  <!-- Проверьте, что путь к файлу верный -->
  <link rel="stylesheet" href="styles.css"> 
</head>
```
#### Шаг 3. Прописываем новое правило (CSS)
Откройте ваш файл styles.css. Добавьте в него новое правило для класса, который вы придумали на Шаге 1.

Обратите внимание: в CSS селектор класса всегда начинается с точки .

```css
/* Это правило уже было для второго абзаца */
.blue-text {
  color: blue;
}

/* А это наше новое правило для третьего абзаца */
.custom-color {
  color: #e67e22; /* Произвольный оранжевый цвет (можно взять любой другой) */
}
```
