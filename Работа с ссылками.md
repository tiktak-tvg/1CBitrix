### Работа с ссылками
#### Что такое ссылка?

> Описание:
> Ссылка (гиперссылка) — это элемент страницы, при клике на который браузер переходит на другой документ, сайт, файл или к определенному месту на этой же странице. Ссылки — основа интернета (гипертекста), они связывают миллионы страниц в единую сеть.

Тег: Для создания ссылки используется парный тег ``<a>`` (от англ. anchor — якорь).

Главный атрибут: ``href (hypertext reference)`` — указывает, куда ведет ссылка.

Пример:

```html
<!-- Ссылка на внешний сайт -->
<a href="https://example.com">Перейти на Example</a>

<!-- Ссылка на другую страницу нашего сайта -->
<a href="about.html">О нас</a>

<!-- Ссылка на файл для скачивания -->
<a href="files/document.pdf">Скачать PDF</a>
```
Полезные атрибуты ссылки:

``target="_blank"`` — открывает ссылку в новой вкладке браузера. (Рекомендуется добавлять ``rel="noopener noreferrer"`` для безопасности).

``title="Текст"`` — показывает всплывающую подсказку при наведении курсора.

``download`` — указывает браузеру, что файл по ссылке нужно скачать, а не открывать.

```html
<a href="https://example.com" target="_blank" rel="noopener noreferrer" title="Откроется в новой вкладке">
  Внешняя ссылка
</a>
```
#### Абсолютные и относительные ссылки
> Описание:
> Путь в атрибуте ``href`` может быть абсолютным или относительным. Это определяет, откуда браузер будет отсчитывать местоположение нужного файла.

##### Абсолютные ссылки
Содержат полный адрес, включая протокол ``http://, https://`` и доменное имя. Они указывают на точное, фиксированное местоположение в интернете. Не зависят от того, где лежит текущий HTML-файл.

Пример:

```html
<a href="https://www.google.com">Поиск Google</a>
<a href="https://ru.wikipedia.org/wiki/HTML">Статья про HTML в Википедии</a>
```
Также абсолютным путем считается путь от корня сайта (начинается с одного слеша ``/``): ``<a href="/contacts">Контакты</a> (ссылается на site.ru/contacts)``.

##### Относительные ссылки
Указывают путь к файлу относительно текущего документа. Они не содержат доменного имени.

Примеры:

Файл в той же папке: ``<a href="page.html">Страница</a>``

Файл в подпапке: ``<a href="docs/page.html">Документ</a>``

Файл уровнем выше (из подпапки): ``<a href="../index.html">На главную</a>``

##### Когда что использовать:

Абсолютные — для ссылок на другие сайты (внешние ресурсы).

Относительные — для ссылок внутри вашего же сайта (навигация между страницами). Это удобно: если вы смените домен сайта, относительные ссылки продолжат работать, а абсолютные — сломаются.

##### Ссылка с якорем
Описание: Якорные ссылки ``anchor links`` позволяют перейти не просто на страницу, а сразу к конкретному блоку на этой странице (например, к разделу «Контакты» в самом низу длинного документа).

Как это работает:

Элементу, к которому нужно перейти, задается уникальный идентификатор ``id``.

В ссылке ``href`` указывается этот ``id`` с символом решётки ``#``.

Пример (переход внутри одной страницы):

```html
<!-- Меню навигации вверху страницы -->
<nav>
  <a href="#about">О нас</a> | 
  <a href="#contacts">Контакты</a>
</nav>

<!-- Много текста... -->
<h2 id="about">О нас</h2>
<p>Информация о компании...</p>

<!-- Много текста... -->
<h2 id="contacts">Контакты</h2>
<p>Телефон: +7 (900) 000-00-00</p>

<!-- Ссылка "Наверх" (возвращает в начало страницы) -->
<a href="#">Наверх ↑</a>
```
Пример (переход на якорь другой страницы):

```html
<!-- Переход на страницу about.html к блоку с id="team" -->
<a href="about.html#team">Наша команда</a>
```
> Важно:
> ``id`` должен быть уникальным на странице (не должно быть двух элементов с ``id="about"``).

##### Практика
Задание: Создайте небольшой сайт-визитку из двух страниц ``index.html`` и ``contacts.html``, используя все виды ссылок.

На странице ``index.html`` создайте навигацию (меню) со ссылками на страницу контактов и на якоря внутри самой страницы (разделы «Услуги» и «О нас»).

Добавьте внешнюю абсолютную ссылку на любой полезный сайт (например, MDN Web Docs).

Внутри страницы сделайте длинный текст, чтобы проверить работу якорей, и ссылку «Наверх».

Создайте страницу ``contacts.html`` и сделайте там ссылку для возврата на главную (относительный путь).

Добавьте ссылку ``mailto``: для отправки письма.

Решение
Файл ``index.html``:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Моя визитка</title>
  <style>
    body { font-family: sans-serif; max-width: 800px; margin: 40px auto; line-height: 1.6; }
    nav { background: #f0f0f0; padding: 10px; border-radius: 8px; margin-bottom: 20px; }
    nav a { margin-right: 15px; text-decoration: none; color: #2980b9; font-weight: bold; }
    nav a:hover { text-decoration: underline; }
    .anchor-target { margin-top: 50px; margin-bottom: 50px; }
    .spacer { height: 400px; background: #fafafa; border: 1px dashed #ddd; display: flex; align-items: center; justify-content: center; color: #999; }
  </style>
</head>
<body>

  <h1>Добро пожаловать на мою визитку</h1>

  <!-- 1. Навигация (относительные ссылки + якоря) -->
  <nav>
    <a href="contacts.html">Связаться со мной</a>
    <a href="#about">О нас</a>
    <a href="#services">Услуги</a>
  </nav>

  <!-- 2. Внешняя абсолютная ссылка -->
  <p>
    Я учусь веб-разработке по документации 
    <a href="https://developer.mozilla.org/ru/" target="_blank" rel="noopener noreferrer" title="Лучшая база знаний по вебу">MDN Web Docs</a>.
  </p>

  <!-- Блок для прокрутки -->
  <div class="spacer">(Текст для создания прокрутки)</div>

  <!-- 3. Якорь "О нас" -->
  <h2 id="about" class="anchor-target">О нас</h2>
  <p>Мы занимаемся созданием качественных и современных сайтов.</p>

  <div class="spacer">(Текст для создания прокрутки)</div>

  <!-- 3. Якорь "Услуги" -->
  <h2 id="services" class="anchor-target">Услуги</h2>
  <ul>
    <li>Верстка сайтов</li>
    <li>Адаптивный дизайн</li>
  </ul>

  <div class="spacer">(Текст для создания прокрутки)</div>

  <!-- Ссылка "Наверх" -->
  <a href="#">↑ Вернуться в начало страницы</a>

</body>
</html>
```

##### Итоговая шпаргалка по ссылкам
```html
<!-- Внешняя абсолютная -->
<a href="https://site.com">Сайт</a>

<!-- Внутренняя относительная -->
<a href="page.html">Страница</a>
<a href="../index.html">Выше на уровень</a>

<!-- В новой вкладке -->
<a href="https://site.com" target="_blank" rel="noopener noreferrer">Сайт</a>

<!-- Якорь на этой же странице -->
<a href="#section">К разделу</a>
<h2 id="section">Раздел</h2>

<!-- Якорь на другой странице -->
<a href="page.html#section">К разделу на другой стр.</a>

<!-- Наверх -->
<a href="#">Наверх</a>

<!-- Почта и телефон -->
<a href="mailto:test@mail.ru">Написать</a>
<a href="tel:+79000000000">Позвонить</a>

<!-- Скачать файл -->
<a href="file.pdf" download>Скачать</a>
```
