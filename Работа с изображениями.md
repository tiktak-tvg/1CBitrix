#### Работа с изображениями в HTML и CSS
Изображения делают сайт живым и наглядным. В веб-разработке есть два основных способа добавить картинку на страницу: через HTML-тег и через CSS-свойство. Давайте разберем оба варианта, их особенности, а также затронем SVG и CSS-фильтры.

##### 1. Как загрузить картинку при помощи HTML?
Описание: Для этого используется одиночный тег ``<img>``. Он не требует закрывающего тега. Главные атрибуты:
- ``src (source)`` — путь к файлу картинки (обязательный).
- ``alt (alternative)`` — альтернативный текст. Он показывается, если картинка не загрузилась, а также озвучивается скринридерами (важно для доступности и SEO).
- ``width и height`` — ширина и высота (можно задавать в пикселях, но лучше делать это через CSS).

Пример:
```html
<!-- Картинка из интернета -->
<img src="https://example.com/cat.jpg" alt="Рыжий кот" width="400">

<!-- Картинка с вашего компьютера (относительный путь) -->
<img src="images/logo.png" alt="Логотип компании">
```
##### 2. Как загрузить картинку при помощи CSS?
Описание: Картинка задается как фон для любого блока (например, ``<div>)``. Для этого используется свойство ``background-image`` с функцией url().

Чтобы фон выглядел красиво, обычно используют дополнительные свойства:
- ``background-size: cover;``  — картинка масштабируется, чтобы полностью заполнить блок (обрезая лишнее).
- ``background-position: center;``  — центрирует картинку.
- ``background-repeat: no-repeat;``  — запрещает повторение картинки (по умолчанию она "мозаичится").

Пример:
```html
<div class="bg-box">Текст поверх картинки</div>
```
```css
.bg-box {
  width: 400px;
  height: 250px;
  color: white; /* Чтобы текст был виден */
  background-image: url('images/background.jpg');
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}
```
##### 3. Основные CSS-свойства картинки
Если вы используете тег <img>, к нему можно применять обычные CSS-свойства для блоков:
- ``width / height:`` размеры. Если задать только width: 100%, высота подстроится автоматически (сохранятся пропорции).
- ``object-fit: cover;:`` очень важное свойство. Заставляет картинку заполнить заданные рамки, обрезая края, но не искажая пропорции.
- ``border-radius:`` скругление углов. 50% делает картинку круглой.
- ``border:`` рамка вокруг картинки.
- ``box-shadow:`` тень от картинки.
- ``opacity:`` прозрачность (от 0 до 1).
- ``vspace`` - вертикальный отступ от изображения до окружающего контента.

Пример:
```css
img.profile {
  width: 150px;
  height: 150px;
  object-fit: cover;
  border-radius: 50%; /* Круглая аватарка */
  border: 3px solid #3498db;
  box-shadow: 0 4px 8px rgba(0,0,0,0.2);
}
```
##### 4. Какой вариант лучше? (``HTML <img> vs CSS background-image``)
Оба варианта хороши, но применяются в разных ситуациях.

Выбирайте ``HTML <img> (тег)``, если:
- Картинка является контентом (фотография в статье, товар в магазине, аватар пользователя).
- Важна доступность (скринридеры читают alt).
- Важна SEO-оптимизация (поисковики индексируют картинки из тегов <img>).
- Пользователю нужно иметь возможность сохранить картинку (правой кнопкой мыши).

Выбирайте ``CSS background-image``, если:
- Картинка носит декоративный характер (фоновый узор, текстура).
- Нужно наложить текст поверх картинки (например, большие баннеры на главной странице).
- Картинка нужна только для оформления, и пользователю не нужно её скачивать.

##### 5. Работа с форматом SVG
Описание: ``SVG (Scalable Vector Graphics)`` — это векторный формат графики. В отличие от JPG или PNG, он не состоит из пикселей, а описывается математическими формулами. Это значит, что SVG идеально масштабируется без потери качества (не мылится при увеличении). Это стандарт для иконок и логотипов.

Как использовать:

- Как обычная картинка: ``<img src="icon.svg" alt="Иконка">``
- Через CSS-фон: ``background-image: url('icon.svg')``;
- Встроенный (Inline) SVG: Код картинки вставляется прямо в HTML.
- Встроенный SVG — самый мощный способ, так как его можно красить и анимировать через CSS.

Пример:
```html
<!-- Встроенная SVG-иконка сердечка -->
<svg width="50" height="50" viewBox="0 0 24 24" fill="none" stroke="red" stroke-width="2">
  <path d="M20.84 4.61a5.5 5.5 0 0 0-7.78 0L12 5.67l-1.06-1.06a5.5 5.5 0 0 0-7.78 7.78l1.06 1.06L12 21.23l7.78-7.78 1.06-1.06a5.5 5.5 0 0 0 0-7.78z"></path>
</svg>
```
(Если добавить класс к тегу <svg>, можно менять его цвет через CSS свойство fill или stroke).

##### 6. Фильтр и изменение картинки
CSS позволяет изменять внешний вид картинки без Photoshop, прямо в браузере, с помощью свойства filter.

Основные фильтры:
- ``blur(5px)`` — размытие.
- ``brightness(150%)`` — яркость.
- ``contrast(200%)`` — контрастность.
- ``grayscale(100%)`` — делает черно-белой.
- ``sepia(100%)`` — эффект старинной фотографии.
- ``hue-rotate(90deg)`` — сдвиг цветового тона.

Фильтры часто используют для эффектов при наведении (hover). Также для изменения размера и поворота используют свойство transform.

Пример:
```css
/* Изначально картинка цветная */
img.effect {
  transition: filter 0.3s ease; /* Плавный переход */
}

/* При наведении курсора картинка становится черно-белой и немного увеличивается */
img.effect:hover {
  filter: grayscale(100%) contrast(120%);
  transform: scale(1.05); /* Увеличение на 5% */
}
```
#### Итоговый пример (все вместе)
Сохраните этот код в файл index.html, чтобы увидеть работу тегов, фильтров, фонов и SVG вживую.
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Работа с изображениями</title>
  <style>
    body {
      font-family: Arial, sans-serif;
      background: #f4f4f4;
      padding: 20px;
      display: flex;
      flex-direction: column;
      gap: 20px;
      align-items: center;
    }

    /* 1. Тег img с эффектами при наведении */
    .hover-img {
      width: 200px;
      height: 230px;
      object-fit: cover;
      border-radius: 12px;
      box-shadow: 0 4px 8px rgba(0,0,0,0.2);
      transition: all 0.4s ease;
      cursor: pointer;
    }

    .hover-img:hover {
      filter: sepia(100%) hue-rotate(-30deg) saturate(200%);
      transform: scale(1.05);
    }

    /* 2. CSS background-image с текстом поверх */
    .bg-banner {
      width: 300px;
      height: 250px;
      background-image: url('images/cat.png');
      background-size: cover;
      background-position: center;
      border-radius: 12px;
      display: flex;
      align-items: center;
      justify-content: center;
      color: yellow;
      font-size: 24px;
      font-weight: bold;

    /* 3. Стилизация встроенного SVG */
    .svg-icon {
      fill: #ccc; /* Серый цвет по умолчанию */
      transition: fill 0.3s;
      cursor: pointer;
    }
    .svg-icon:hover {
      fill: #e74c3c; /* Красный при наведении */
    }
  </style>
</head>
<body>

  <h2>1. Тег &lt;img&gt; с CSS-фильтром</h2>
  <img class="hover-img" src="images/cat.png" alt="Кот">

  <h2>2. Фон через CSS</h2>
  <div class="bg-banner">Текст поверх фона</div>

  <h2>3. Встроенный SVG (наведи)</h2>
  <svg class="svg-icon" width="60" height="60" viewBox="0 0 24 24" xmlns="http://www.w3.org/2000/svg">
    <path d="M12 21.35l-1.45-1.32C5.4 15.36 2 12.28 2 8.5 2 5.42 4.42 3 7.5 3c1.74 0 3.41.81 4.5 2.09C13.09 3.81 14.76 3 16.5 3 19.58 3 22 5.42 22 8.5c0 3.78-3.4 6.86-8.55 11.54L12 21.35z"/>
  </svg>

</body>
</html>
```
