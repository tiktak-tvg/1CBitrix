### Ссылки. Задание
Создадим вторую html-страницу, например, about.html

На странице about.html расположим заголовок первого уровня с текстом “Добро пожаловать на нашу страницу” и загрузить картинку приветствия (скачай картинку, перейдя по ссылке)

Вернемся на страницу index.html. Если у тебя остались картинки, можешь их не удалять. Внизу картинок добавь ссылку на страницу about.html

Загрузи в браузере страницу index.html и попробуй нажать по ссылке. Вместе страницы index.html должна открыться страница about.html

#### Шаг 1
Как должен выглядеть ваш index.html (я добавил картинку-заглушку и саму ссылку):
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Главная страница</title>
  <style>
    body {
      font-family: Arial, sans-serif;
      text-align: center;
      padding: 40px;
    }
    .link-button {
      display: inline-block;
      margin-top: 20px;
      padding: 10px 20px;
      background-color: #3498db;
      color: white;
      text-decoration: none;
      border-radius: 6px;
      font-weight: bold;
    }
    .link-button:hover {
      background-color: #2980b9;
    }
  </style>
</head>
<body>

  <h1>Главная страница сайта</h1>
  
  <p>Здесь расположены наши картинки:</p>
  
  <!-- Пример картинки на главной странице -->
  <img src="https://images.unsplash.com/photo-1514888286974-6c03e2ca1dba?ixlib=rb-4.0.3&auto=format&fit=crop&w=400&q=80" alt="Кот" style="max-width: 100%; border-radius: 8px;">

  <br> <!-- Перенос строки, чтобы ссылка была под картинкой -->

  <!-- Ссылка на страницу about.html -->
  <a href="about.html" class="link-button">
    Перейти на страницу "О нас" →
  </a>

</body>
</html>
```

#### Шаг 2
Создаем страницу about.html

Создайте новый файл about.html в той же папке, где лежит ваш index.html (в папке Academy).
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>О нас</title>
  <style>
    body {
      font-family: Arial, sans-serif;
      text-align: center; /* Центрируем контент для красоты */
      padding: 40px;
    }
    h1 {
      color: #2c3e50;
    }
    img {
      max-width: 100%;
      border-radius: 12px;
      box-shadow: 0 4px 10px rgba(0,0,0,0.15);
      margin-bottom: 20px;
    }
  </style>
</head>
<body>

  <h1>Добро пожаловать на нашу страницу</h1>
  
  <!-- Картинка приветствия. Если вы скачали её, замените src на локальный путь, например: src="images/welcome.jpg" -->
  <img src="https://images.unsplash.com/photo-1577962917302-cd874c4e31d2?ixlib=rb-4.0.3&auto=format&fit=crop&w=600&q=80" alt="Приветствие">
  
  <br>

  <!-- Ссылка для возврата на главную страницу (относительный путь) -->
  <a href="index.html" style="color: #2980b9; font-weight: bold; text-decoration: none;">
    ← Вернуться на главную
  </a>

</body>
</html>
```
