### Работа со стилями — практическое задание
#### Шаг 1. Создаём папку Academy
Структура проекта после выполнения всех шагов будет такой:

```text
Academy/
├── myAcademy.html
└── Styles/
    └── styles.css
```
Пояснение:
```text
Academy — корневая папка проекта;

myAcademy.html — HTML-страница;

Styles — вложенная папка для CSS;

styles.css — файл со стилями.
```
#### Шаг 2. Создаём файл myAcademy.html
В папке Academy создаём файл myAcademy.html.

#### Шаг 3. Прописываем обязательные теги структуры
Минимальный каркас HTML-документа: <!DOCTYPE html>, <html>, <head>, <body>.

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Моя Академия</title>
</head>
<body>

</body>
</html>
```
Пояснение:
```txt
<!DOCTYPE html> — говорит браузеру, что это HTML5;

<html lang="ru"> — корень документа, язык — русский;

<head> — служебная информация (кодировка, viewport, title, подключение стилей);

<body> — видимое содержимое страницы.
```
#### Шаг 4. Добавляем заголовок первого уровня
Внутри ``<body>`` добавляем ``<h1>``:

```html
<h1>Добро пожаловать на вводный курс по HTML</h1>
```
#### Шаг 5. Добавляем первый абзац
```html
<p>Мы изучим: язык гипертекстовой разметки HTML, каскадную таблицу стилей CSS, поработаем с текстом, с ссылками, изображениями, таблицами и HTML-формами.</p>
```
#### Шаг 6. Добавляем второй абзац
```html
<p>А еще мы познакомимся с языком программирования PHP и с системой управления содержимым bitrix.</p>
```
#### Шаг 7. Создаём папку Styles
В папке Academy создаём вложенную папку Styles (регистр важен: именно Styles, с большой буквы).

```text
Academy/
└── Styles/
```
#### Шаг 8. Создаём файл styles.css
В папке Styles создаём файл styles.css. Пока он пустой — заполним на шагах 11–13.

```text
Academy/
└── Styles/
    └── styles.css
```
#### Шаг 9. Подключаем styles.css на странице
В <head> файла myAcademy.html добавляем тег <link>:

```html
<link rel="stylesheet" href="Styles/styles.css">
```
Пояснение пути:
```text
Styles/styles.css — относительный путь: из myAcademy.html заходим в папку Styles и берём файл styles.css;

rel="stylesheet" — тип подключаемого файла (таблица стилей);

href — путь до файла.
```
Итоговый ``myAcademy.html`` после шага 9:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Моя Академия</title>
  <link rel="stylesheet" href="Styles/styles.css">
</head>
<body>
  <h1>Добро пожаловать на вводный курс по HTML</h1>
  <p>Мы изучим: язык гипертекстовой разметки HTML, каскадную таблицу стилей CSS, поработаем с текстом, с ссылками, изображениями, таблицами и HTML-формами.</p>
  <p>А еще мы познакомимся с языком программирования PHP и с системой управления содержимым bitrix.</p>
</body>
</html>
```
#### Шаг 10. Правило для цвета фона
В ``styles.css`` задаём фон страницы. Фон логично задавать через селектор ``body``.

```css
body {
  background-color: #f4f4f4;
}
```
```text
Пояснение:

body — селектор, выбирает тег <body>;

background-color — свойство фона;

#f4f4f4 — светло-серый цвет в HEX.
```
Можно использовать и другие варианты:
```css
body {
  background-color: lightblue;       /* именованный цвет */
  /* или */
  background-color: rgb(240, 248, 255);
}
```
#### Шаг 11. Правило для цвета шрифта заголовка ``h1``
```css
h1 {
  color: #2c3e50;
}
```
```text
Пояснение:

h1 — селектор тега заголовка первого уровня;

color — цвет текста;

#2c3e50 — тёмно-синий оттенок.
```
#### Шаг 12. Правило для цвета шрифта абзацев
```css
p {
  color: #333333;
}
```
```text
Пояснение:

p — селектор всех абзацев на странице;

color: #333333 — тёмно-серый цвет текста.
```
Итоговый файл Styles/styles.css
```css
body {
  background-color: #f4f4f4;
}

h1 {
  color: #2c3e50;
}

p {
  color: #333333;
}
```
#### Проверка результата
Открываем Academy/myAcademy.html в браузере. Должно получиться:

- светлый фон страницы ``(#f4f4f4);``
- заголовок «Добро пожаловать на вводный курс по HTML» тёмно-синего цвета ``(#2c3e50);``
- два абзаца тёмно-серого цвета ``(#333333).``

##### Возможные ошибки и как их избежать
Ошибка	|Что происходит	|Как исправить
------- | -------------- | ------------------
``href="styles.css"`` вместо ``Styles/styles.css``	 |Стили не подключаются (404)	 |Указать правильный относительный путь
Папка называется ``styles``, а в ``href — Styles``	 |404 на Linux-хостинге	 |Соблюдать регистр
``<link>`` стоит вне ``<head>``	 |Стили применяются, но это невалидно	 |Перенести ``<link> в <head>``
Опечатка в свойстве (colour, backgroud)	 |Свойство не работает	 |Проверить написание через DevTools
Нет ``<!DOCTYPE html>``	 |Браузер может включить режим совместимости	 |Добавить ``<!DOCTYPE html>`` первой строкой

Как проверить подключение стилей
- Открыть страницу в браузере.
- Нажать F12 → вкладка Network/Сеть → перезагрузить (F5).
- Найти styles.css — статус должен быть 200. Если 404 — неверный путь.
- Во вкладке Elements/Элементы выбрать ``body, h1, p`` и посмотреть применённые стили справа.

##### Дополнительное задание
Чтобы закрепить материал, можно добавить в ``styles.css`` ещё несколько правил:
```css
body {
  background-color: #f4f4f4;
  font-family: Arial, sans-serif;
  margin: 0;
  padding: 20px;
}

h1 {
  color: #2c3e50;
  text-align: center;
}

p {
  color: #333333;
  font-size: 16px;
  line-height: 1.6;
  max-width: 800px;
  margin: 12px auto;
}

body {
  padding: 0 16px;
}
```
Эти правила делают страницу аккуратнее: центрируют заголовок, задают шрифт и удобный межстрочный интервал, ограничивают ширину абзацев для читаемости.
