#### Работа с изображениями в HTML и CSS
Изображения делают сайт живым и наглядным. В веб-разработке есть два основных способа добавить картинку на страницу: через HTML-тег и через CSS-свойство. Давайте разберем оба варианта, их особенности, а также затронем SVG и CSS-фильтры.

##### 1. Как загрузить картинку при помощи HTML?
Описание: Для этого используется одиночный тег ``<img>``. Он не требует закрывающего тега. Главные атрибуты:
- ``src (source)`` — путь к файлу картинки (обязательный).
- ``alt (alternative)`` — альтернативный текст. Он показывается, если картинка не загрузилась, а также озвучивается скринридерами (важно для доступности и SEO).
- ``width и height`` — ширина и высота (можно задавать в пикселях, но лучше делать это через CSS).

Пример:
```html
<!-- Картинка из интернета -->
<img src="https://example.com/cat.jpg" alt="Рыжий кот" width="400">

<!-- Картинка с вашего компьютера (относительный путь) -->
<img src="images/cat.png" alt="Логотип компании">
```
##### 2. Как загрузить картинку при помощи CSS?
Описание: Картинка задается как фон для любого блока (например, ``<div>)``. Для этого используется свойство ``background-image`` с функцией url().

Чтобы фон выглядел красиво, обычно используют дополнительные свойства:
- ``background-size: cover;``  — картинка масштабируется, чтобы полностью заполнить блок (обрезая лишнее).
- ``background-position: center;``  — центрирует картинку.
- ``background-repeat: no-repeat;``  — запрещает повторение картинки (по умолчанию она "мозаичится").

Пример:
```html
<div class="bg-box">Текст поверх картинки</div>
```
```css
.bg-box {
  width: 400px;
  height: 250px;
  color: white; /* Чтобы текст был виден */
  background-image: url('images/background.jpg');
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}
```

##### 3. Основные CSS-свойства картинки
Если вы используете тег <img>, к нему можно применять обычные CSS-свойства для блоков:
- ``width / height:`` размеры. Если задать только width: 100%, высота подстроится автоматически (сохранятся пропорции).
- ``object-fit: cover;:`` очень важное свойство. Заставляет картинку заполнить заданные рамки, обрезая края, но не искажая пропорции.
- ``border-radius:`` скругление углов. 50% делает картинку круглой.
- ``border:`` рамка вокруг картинки.
- ``box-shadow:`` тень от картинки.
- ``opacity:`` прозрачность (от 0 до 1).
- ``vspace`` - вертикальный отступ от изображения до окружающего контента.

Пример:
```css
img.profile {
  width: 150px;
  height: 150px;
  object-fit: cover;
  border-radius: 50%; /* Круглая аватарка */
  border: 3px solid #3498db;
  box-shadow: 0 4px 8px rgba(0,0,0,0.2);
}
```
##### 4. Какой вариант лучше? (``HTML <img> vs CSS background-image``)
Оба варианта хороши, но применяются в разных ситуациях.

Выбирайте ``HTML <img> (тег)``, если:
- Картинка является контентом (фотография в статье, товар в магазине, аватар пользователя).
- Важна доступность (скринридеры читают alt).
- Важна SEO-оптимизация (поисковики индексируют картинки из тегов <img>).
- Пользователю нужно иметь возможность сохранить картинку (правой кнопкой мыши).

Выбирайте ``CSS background-image``, если:
- Картинка носит декоративный характер (фоновый узор, текстура).
- Нужно наложить текст поверх картинки (например, большие баннеры на главной странице).
- Картинка нужна только для оформления, и пользователю не нужно её скачивать.


#### Свойство тега img 
У тега картинки существует прекрасное свойство, ``object-fit``, которое управляет размещением элемента, если ширина и высота отличаются от его настоящего размера. Вместо cover можно использовать значение contain.

Рассмотрим функции, которые могут быть полезны.
- 1.``linearGradient``. Из названия мы понимаем, что данная функция добавляет линейный градиент к фону элемента. Она выступает значением свойства background-image или background (пс, позже будет пример).
- 2.``background-origin``. Когда мы назначаем элементу фон в виде изображения или сплошного цвета, то по умолчанию он закрашивает всю область границы элемента. Но это можно изменить при помощи свойства background-origin. Оно принимает одно из трёх значений: 
    - ``border-box (значение по умолчанию)`` - фон располагается относительно рамки.
    - ``padding-box`` - фон расположен относительно поля отступа.
    - ``content-box`` - фон располагается относительно поля содержимого.
- 3.``background-position``. Устанавливает начальную позицию для каждого фонового изображения. В background-position можно подставлять либо процентное, либо абсолютное значение, которые указывают смещение изображения от одного из четырёх краёв области позиционирования (верхняя, правая, нижняя, левая точка).

Вот готовый пример, в котором используются все три запрошенных свойства:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Свойства фона CSS</title>
  <style>
    body {
      font-family: Arial, sans-serif;
      padding: 40px;
      background-color: #f4f4f4;
    }

    .example-box {
      /* Задаем размеры и отступы для наглядности */
      width: 250px;
      height: 150px;
      padding: 20px;
      
      /* Полупрозрачная рамка, чтобы было видно, как под нее заходит фон */
      border: 15px solid rgba(0, 0, 0, 0.2); 
      
      /* Текст внутри, чтобы видеть content-box */
      color: #333;
      font-weight: bold;

      /* 1. linearGradient - градиент от желтого к розовому */
      /* Чтобы увидеть сдвиг и origin, уменьшаем размер градиента до 100х100px */
      background-image: linear-gradient(135deg, yellow, pink);
      background-size: 100px 100px; 
      background-repeat: no-repeat; /* Запрещаем повторение */

      /* 2. background-origin - меняем расположение фона относительно рамки */
      /* border-box означает, что фон начинается от внешнего края рамки */
      background-origin: border-box; 

      /* 3. background-position - сдвигаем фон на 50 пикселей */
      background-position: 50px 50px; 
      
      /* Фоновый цвет страницы (для контраста) */
      background-color: #fff;
    }
    .gradient{
	   background: linear-gradient(to top, #fdd034, #d52d8b);
	   height: 100px;
	   width: 500px;
	   border: 20px solid cornflowerblue;
	   padding: 20px;
	}
	.bOrigin{
	   background-origin: content-box;
	   background-repeat: no-repeat;
	}
	.bPosition
	{
	   background-position: 50px;
	}

  </style>
</head>
<body>

  <h3>Демонстрация свойств фона:</h3>
  
  <div class="example-box">
    Этот блок имеет прозрачную рамку. Фон начинается под рамкой (border-box) и сдвинут вправо и вниз на 50px.
  </div>
<br>
<div class="gradient bOrigin bPosition"></div>
</body>
</html>
```

##### 5. Работа с форматом SVG
Описание: ``SVG (Scalable Vector Graphics)`` — это векторный формат графики. В отличие от JPG или PNG, он не состоит из пикселей, а описывается математическими формулами. Это значит, что SVG идеально масштабируется без потери качества (не мылится при увеличении). Это стандарт для иконок и логотипов.

Как использовать:

- Как обычная картинка: ``<img src="icon.svg" alt="Иконка">``
- Через CSS-фон: ``background-image: url('icon.svg')``;
- Встроенный (Inline) SVG: Код картинки вставляется прямо в HTML.
- Встроенный SVG — самый мощный способ, так как его можно красить и анимировать через CSS.

Пример:
```html
<!-- Встроенная SVG-иконка сердечка -->
<svg width="50" height="50" viewBox="0 0 24 24" fill="none" stroke="red" stroke-width="2">
  <path d="M20.84 4.61a5.5 5.5 0 0 0-7.78 0L12 5.67l-1.06-1.06a5.5 5.5 0 0 0-7.78 7.78l1.06 1.06L12 21.23l7.78-7.78 1.06-1.06a5.5 5.5 0 0 0 0-7.78z"></path>
</svg>
```
(Если добавить класс к тегу <svg>, можно менять его цвет через CSS свойство fill или stroke).

##### 6. Фильтр и изменение картинки
CSS позволяет изменять внешний вид картинки без Photoshop, прямо в браузере, с помощью свойства filter.

Основные фильтры:
- ``blur(5px)`` — размытие.
- ``brightness(150%)`` — яркость.
- ``contrast(200%)`` — контрастность.
- ``grayscale(100%)`` — делает черно-белой.
- ``sepia(100%)`` — эффект старинной фотографии.
- ``hue-rotate(90deg)`` — сдвиг цветового тона.

Фильтры часто используют для эффектов при наведении (hover). Также для изменения размера и поворота используют свойство transform.

Пример:
```css
/* Изначально картинка цветная */
img.effect {
  transition: filter 0.3s ease; /* Плавный переход */
}

/* При наведении курсора картинка становится черно-белой и немного увеличивается */
img.effect:hover {
  filter: grayscale(100%) contrast(120%);
  transform: scale(1.05); /* Увеличение на 5% */
}
```

##### 7. Свойство background-repeat 
Позволяет управлять повтором фонового изображения. То есть, если наш контейнер, в который вложена картинка, больше самой картинки, то возникает повторение изображения.

По умолчанию заданное значение свойства - ``repeat``, то есть фоновая картинка будет повторяться по вертикали и по горизонтали. 

Однако это не единственное значение. ``background-repeat`` может принимать: 
- ``no-repeat`` - картинка будет отображена только один раз;
- ``repeat-x`` - картинка повторяется по горизонтали 

Пример:
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Свойство background-repeat</title>
  <style>
    body {
      font-family: Arial, sans-serif;
      padding: 20px;
      background-color: #f9f9f9;
    }

    h2 {
      font-size: 18px;
      color: #333;
      margin-bottom: 10px;
      margin-top: 30px;
    }

    /* Общие стили для всех демонстрационных блоков */
    .demo-box {
      width: 300px;
      height: 150px;
      border: 2px solid #2c3e50;
      margin-bottom: 10px;
      
      /* Задаем фоновую картинку (синий квадрат с белым кругом) */
      /* Я использую SVG-код прямо в строке, чтобы картинка всегда загружалась */
      background-image: url('data:image/svg+xml;utf8,<svg xmlns="http://www.w3.org/2000/svg" width="50" height="50"><rect width="50" height="50" fill="%233498db"/><circle cx="25" cy="25" r="15" fill="white"/></svg>');
    }

    /* 1. repeat (по умолчанию) */
    .box-repeat {
      background-repeat: repeat;
    }

    /* 2. no-repeat */
    .box-no-repeat {
      background-repeat: no-repeat;
      /* Немного сдвинем картинку в центр, чтобы она не прилипала к левому верхнему углу */
      background-position: center; 
    }

    /* 3. repeat-x (только по горизонтали) */
    .box-repeat-x {
      background-repeat: repeat-x;
    }

    /* 4. repeat-y (только по вертикали) */
    .box-repeat-y {
      background-repeat: repeat-y;
    }
  </style>
</head>
<body>

  <h1>Свойство background-repeat</h1>
  <p>Все блоки имеют размер 300x150 пикселей. Размер фоновой картинки — 50x50 пикселей. Посмотрите, как меняется поведение:</p>

  <h2>1. repeat (значение по умолчанию)</h2>
  <p>Картинка повторяется и по горизонтали, и по вертикали, заполняя весь блок.</p>
  <div class="demo-box box-repeat"></div>

  <h2>2. no-repeat</h2>
  <p>Картинка отображается только один раз (я добавил центрирование для красоты).</p>
  <div class="demo-box box-no-repeat"></div>

  <h2>3. repeat-x</h2>
  <p>Картинка повторяется только по горизонтали (вдоль оси X). Образуется одна полоса сверху.</p>
  <div class="demo-box box-repeat-x"></div>

  <h2>4. repeat-y</h2>
  <p>Картинка повторяется только по вертикали (вдоль оси Y). Образуется одна полоса слева.</p>
  <div class="demo-box box-repeat-y"></div>

</body>
</html>
```
