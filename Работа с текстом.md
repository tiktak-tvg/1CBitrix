#### Работа со стилями
Описание: Текстовые теги задают смысл (заголовок, важность, акцент), а CSS — внешний вид (цвет, размер, шрифт, отступы). Правильный подход: структура в HTML, оформление — в CSS.

Пример:
```html
<p class="intro">Вводный абзац текста.</p>
<p>Обычный <strong>важный</strong> и <em>акцентный</em> текст.</p>
```
```css
.intro {
  font-size: 18px;
  color: #2c3e50;
  line-height: 1.6;
}

strong {
  color: #c0392b;
}

em {
  font-style: italic;
  color: #2980b9;
}
```
Пояснение:
```
<strong> и <em> несут смысловую нагрузку (важность и акцент);

через CSS можно менять их вид, но не стоит заменять <strong> просто жирным шрифтом ради оформления — семантика важна для поисковиков и скринридеров.
```
#### Заголовки
Описание: Заголовки бывают шести уровней: ``<h1>`` — самый важный, ``<h6>`` — наименее важный. На странице обычно один ``<h1>`` и далее по иерархии: ``<h2>, <h3> и т.д.`` Пропускать уровни (например, с ``<h1>`` сразу на ``<h4>``) не рекомендуется — это нарушает структуру документа.

Пример:

```html
<h1>Главный заголовок страницы</h1>

<h2>Раздел 1</h2>
<p>Текст первого раздела.</p>

<h3>Подраздел 1.1</h3>
<p>Текст подраздела.</p>

<h2>Раздел 2</h2>
<p>Текст второго раздела.</p>

<h6>Самый мелкий заголовок</h6>
```
Пояснение:
```
<h1> — тема всей страницы;

<h2> — крупные разделы;

<h3> — подразделы внутри <h2>;

<h6> — самый низкий уровень, используется редко.
```
#### Оформление заголовков через CSS:
```css
h1 {
  font-size: 32px;
  color: #2c3e50;
  text-align: center;
}

h2 {
  font-size: 24px;
  color: #34495e;
  border-bottom: 2px solid #3498db;
  padding-bottom: 6px;
}

h3 {
  font-size: 20px;
  color: #7f8c8d;
}
```
Важно: уровень заголовка выбирают по смыслу, а не по размеру шрифта. Если нужен ``<h2>``, но визуально крупнее — меняйте размер через CSS, а не ставьте ``<h1>``.

#### Красим текст всей страницы в оранжевый через внешний CSS

##### Структура проекта
```text
project/
├── index.html
└── styles/
    └── styles.css
```
Файл index.html уже подключает стили строкой:

```html
<link rel="stylesheet" href="styles/styles.css">

Значит, правим именно styles/styles.css.
```
##### Решение 1. Через селектор body (рекомендуется)
Текст в вашем HTML лежит прямо в ``<body>``, без обёртки в ``<p>``. Свойство color наследуется, поэтому достаточно задать его на body — и весь текст внутри станет оранжевым.
```css
body {
  color: orange;
}
```
Результат: весь текст страницы ``(«Майк Тайсон за карьеру боксера...»)`` отображается оранжевым.

##### Решение 2. Через универсальный селектор *
Если хочется «наверняка» покрасить каждый элемент:
```css
* {
  color: orange;
}
```
Результат: тот же — весь текст оранжевый. Минус — правило применится ко всем элементам, что может помешать позже, когда вы начнёте задавать цвета отдельным блокам (придётся повышать специфичность). Для учебного примера работает.

##### Решение 3. Через селектор типа html
Можно задать цвет на корневом элементе — он тоже наследуется:
```css
html {
  color: orange;
}
```
Результат: весь текст страницы оранжевый.

Способ	|Когда использовать
------- | ----------------------
``body { color: orange; }``	|Базовый цвет текста для всей страницы — лучший вариант
``* { color: orange; }``	 |Быстрый «покрасить всё», но грубо
``html { color: orange; }``	 |Работает, но body нагляднее

##### Рекомендую  
> - Решение 1 — оно самое предсказуемое: задаёт базовый цвет текста, который наследуют все элементы, но при необходимости дочерние элементы можно переопределить своими стилями.

```css
body {
  color: orange;
  font-family: Arial, sans-serif;
  font-size: 18px;
  line-height: 1.6;
  padding: 20px;
}
```

```html
Чем <b>/<i> отличаются от <strong>/<em>

<b> и <i> — только визуальные теги, без смысловой нагрузки;

<strong> и <em> — семантические: браузер делает жирный/курсив, но также говорит поисковикам, скрин ридерам и другим программам о важности или акценте.
```

Практическое правило:
```
важное предупреждение или ключевая фраза — <strong>;

логический акцент в предложении — <em>;

просто «сделать жирным для вида» — <b>;

иностранное слово, название, термин без акцента — <i>.
```

#### Чем ``<span>`` отличается от ``<div>``
``<span>`` — строчный контейнер: не разрывает строку, занимает ширину по содержимому. Для выделения части текста в предложении.

``<div>`` — блочный контейнер: занимает всю ширину, начинает новую строку. Для группировки блоков.

***

```html
<p>Текст с <span style="color: red;">красным словом</span> внутри.</p>

<div style="color: red;">
  <p>Целый блок красный.</p>
</div>
br vs wbr
<br> — принудительный перенос. Браузер обязан перенести строку.

<wbr> — подсказка браузеру: «если нужно, можешь перенести здесь». Без переноса текст остаётся как есть.
```

```html
<p>Первая строка.<br>Вторая строка — принудительно.</p>

<p style="max-width: 150px;">
  Электро<wbr>энцефало<wbr>графия — слово, которое может переноситься
  в указанных точках, если не помещается в блок.
</p>
bdo vs bdi
<bdo dir="rtl"> — принудительно разворачивает направление текста.

<bdi> — изолирует текст с другим направлением, чтобы он не «ломал» окружающий. Удобно для имён на арабском/иврите в русском/английском тексте.
```

***

```html
<p>Обычно: Hello!</p>
<p>Развёрнуто: <bdo dir="rtl">Hello!</bdo></p>

<p>Пользователь <bdi>محمد</bdi> оставил отзыв.</p>
```
Проверка

Сохраните index.html.

Откройте в браузере.

Убедитесь, что:

``<ul>`` показывает маркеры, <ol> — номера;

``<dl>`` показывает термин и его описание с отступом;

``<code>, <var>, <samp>`` — моноширинным шрифтом (у нас ещё и подсвечены цветом);

``<span>`` не разрывает строку, <br> переносит, <hr> рисует линию;

``<wbr>`` позволяет браузеру перенести длинное слово в узком блоке;

``<bdo dir="rtl">`` разворачивает текст, <bdi> изолирует.

Откройте F12 → Elements, чтобы увидеть, как браузер применяет стили по умолчанию к каждому тегу.
