### Создать несколько заголовков с пунктирной рамкой и текстом по центру.
- Выровнять заголовки по центру
- Задать рамку вокруг заголовков

<img width="841" height="338" alt="image" src="https://github.com/user-attachments/assets/5ad5c8eb-5ea9-430a-8877-7d17340c882e" />

Для этого отлично подойдут CSS-свойства text-align (для центрирования) и border (для рамки).

Вот готовый код, который воспроизводит этот дизайн.

#### Файл index-text.html
```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Заголовки с рамкой</title>
  <link rel="stylesheet" href=""css/styles.css">
</head>
<body>

  <h2 class="dotted-box">Ш Б</h2>
  <h2 class="dotted-box">М Н К</h2>
  <h2 class="dotted-box">Ы М Б Ш</h2>
  <h2 class="dotted-box">Б Ы Н К М</h2>
  <h2 class="dotted-box">П Н Ш М К</h2>
  <h2 class="dotted-box">Б И Ш И Н К М</h2>

</body>
</html>
```
#### Файл styles-text.css
```css
/* Общие стили для страницы (по желанию) */
body {
  font-family: "Times New Roman", Times, serif; /* Шрифт как на картинке */
  max-width: 600px;
  margin: 40px auto;
}

/* Стили для наших заголовков */
.dotted-box {
  text-align: center;          /* Выравниваем текст по центру */
  border: 2px dotted black;    /* Задаем пунктирную рамку толщиной 2px */
  padding: 10px;               /* Внутренний отступ, чтобы текст не прилипал к рамке */
  margin-bottom: 15px;         /* Внешний отступ снизу, чтобы блоки не слипались */
  font-size: 24px;             /* Размер шрифта (можно настроить по вкусу) */
  font-weight: bold;           /* Жирное начертание */
}
```
Разбор использованных свойств:
text-align: center; — выравнивает текст внутри блока строго по центру (как требовалось в задании).

border: 2px dotted black; — это сокращенная запись.

2px — толщина рамки;

dotted — тип линии (именно пунктир, как на вашей картинке; если нужна сплошная — пишут solid);

black — цвет линии.

padding: 10px; — добавляет пространство внутри рамки, чтобы текст не касался ее краев.

margin-bottom: 15px; — добавляет пространство снаружи (снизу), чтобы рамки разных заголовков не прилипали друг к другу.
