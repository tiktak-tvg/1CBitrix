### Строчный / блочный элемент
- Блочные элементы

#### Блочные элементы

Блочный элемент представляет собой прямоугольник, который по умолчанию занимает всю доступную ширину страницы, а длина элемента зависит от его содержимого. Т

акой элемент всегда начинается с новой строки (располагается под предыдущим элементом). Примеры блочных элементов: ``<div>``, ``<p>``, ``<ul>``, ``<ol>``, ``<h1>`` и т. д.

Смотри, слово “Алоха” заключено в тег ``<div>``

``<div class = “bloc_element”>Алоха</div>``

и по сути он занимает всю ширину родителя (в нашем случае, всю ширину  страницы).

Если мы добавим еще один тег <div>, то он будет располагаться на новой строке… Это и понятно, он не влез в первую строку, поэтому и переносится на вторую.

#### Строчные элементы
Строчный элемент не переносится на новую строку, а располагается на той же строке, что и предыдущий элемент. Ширина зависит лишь от содержимого и настроек CSS. 

В нем может находиться только контент и другие строчные элементы. Блочные элементы в строчные вкладывать нельзя. Примеры строчных элементов: ``<a>``, ``<span>``, ``<strong>``, ``<em>``, ``<img>`` и т. д.

Помнишь тег ``<span>``? Думаю, когда ты знакомился с первым модуле и внимательно смотрел курс,  ты видел этот тег (если нет, то вернись в предыдущие темы). 

Теперь настало время понять, что он означает. Дело в том, что если взять фрагмент текста и поместить его в тег <span>, то текст автоматически становится строчным и занимает теперь не всю ширину родителя, а лишь доступную ему (зависит от содержимого).

#### 1. Блочные элементы (Block-level)
Блочный элемент ведет себя как «кирпич» или «коробка».

Характеристики:
- Всегда начинается с новой строки.
- По умолчанию занимает всю доступную ширину родительского контейнера (100%), даже если внутри мало текста.
- Можно задавать ширину (width) и высоту (height).
- Можно задавать все отступы (margin и padding) со всех четырех сторон.
- Внутри себя может содержать другие блочные и строчные элементы.

Примеры тегов:
```
<div>, <p>, <h1>...<h6>, <ul>, <ol>, <li>, <header>, <footer>, <section>, <form>, <table>.
```
Пример работы:

```html
<div style="background-color: #ffcccc; border: 1px solid red;">
  Это блочный элемент div. Он занял всю строку.
</div>
<div style="background-color: #ccffcc; border: 1px solid green;">
  А это второй блочный элемент. Он спрыгнул на новую строку.
</div>
(В браузере вы увидите два прямоугольника, расположенных друг под другом).
```
#### 2. Строчные элементы (Inline-level)
Строчный элемент ведет себя как «слово в предложении».

Характеристики:
- НЕ начинает новую строку. Элементы идут друг за другом слева направо, пока хватает места.
- Занимает только ту ширину, которая необходима для его содержимого.
- Нельзя задать ширину (width) и высоту (height). Они игнорируются.
- Верхние и нижние отступы (margin-top, margin-bottom, padding-top, padding-bottom) не сдвигают другие элементы.
- Внутри себя может содержать только текст и другие строчные элементы. Внутрь <span> или <a> нельзя вкладывать <div> или <p>.

Примеры тегов:
```
<span>, <a>, <strong>, <em>, <b>, <i>, <u>, <img> (формально это строчный элемент), <button>, <input>, <br>.
```
Пример работы:
```html
<p style="border: 1px solid blue;">
  Это абзац (блочный). А внутри него 
  <span style="background-color: yellow; border: 1px solid orange;">
    вот этот span — строчный
  </span>
  <span style="background-color: cyan;">
    а вот этот второй span
  </span>
  они стоят в одной строке!
</p>
```
Сравнение в одной таблице

Характеристика	|Блочные (block)	|Строчные (inline)
--------------- | --------------- | ----------------------------
Новая строка	 |Да, всегда	 |Нет, текут в строке
Ширина	 |Вся доступная (100%)	 |По размеру содержимого
width и height	 |Работают	 |Не работают (игнорируются)
Отступы (margin/padding)	 |Работают со всех сторон	 |Работают только слева и справа
Вложение	 |Могут содержать блоки и строчные	 |Могут содержать только строчные
Где живет	 |Каркас страницы, блоки	 |Выделение части текста

#### Строчный-блочный элемент ``(inline-block)``

В CSS есть «гибридный» режим отображения: ``display: inline-block``.

Он берет лучшее от обоих типов:
- Как строчный — элементы стоят в одной строке и идут друг за другом.
- Как блочный — им можно задавать ширину, высоту и все отступы.

```css
.my-button {
  display: inline-block; /* включает гибридный режим */
  width: 150px;
  padding: 10px;
}
(Очень часто используется для верстки кнопок, меню или карточек товаров).
```
#### Как изменить поведение элемента? (display)

С помощью CSS-свойства display можно легко превратить любой элемент в любой другой.

``display: block;`` — сделать элемент блочным.

``display: inline;`` — сделать строчным.

``display: inline-block;`` — сделать гибридным.

``display: none;`` — полностью скрыть элемент.

Пример: Иногда нужно сделать ссылку <a>, которая по умолчанию строчная, блочной, чтобы превратить её в большую кнопку на всю ширину:

```css
a.btn {
  display: block;       /* Превращаем строчную ссылку в блок */
  background: #3498db;
  color: white;
  padding: 15px;
  text-align: center;
  text-decoration: none;
}
```
#### Главное правило (Частая ошибка новичков)
Никогда не вкладывайте блочный элемент внутрь строчного.

Браузер может попытаться исправить разметку сам, и верстка «поедет».

#### Так делать нельзя:
```html
<span>
  <div>Текст в блоке</div> <!-- Грубая ошибка! -->
</span>
```
#### А так можно (и нужно):
```html
<div>
  <span>Текст в строчном элементе</span> <!-- Блок содержит строчный -->
</div>
```
